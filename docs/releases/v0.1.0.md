# mojo-pyformat v0.1.0

**Released:** 2026-10-21 · **Commit:** `a66c107` · **Previous:** first release

## What it does

Python's `format()` for numbers in Mojo, with the same digits: `{:.Nf}`, thousands separators, `g`, `e`, and `%`, rounded on the double's exact binary value as CPython does.

## Highlights

- Identical to Python on 10,846 cases and on a wider 42,856-case set (random bit patterns, subnormals, precision up to 100, numbers to 1.8e308).
- `.2f` is 5.9x faster than Python (1M values: 40 ms vs 234 to 242 ms); `g` and `e` about 2x.
- `format(2.675, '.2f')` gives `2.67`, as Python does, because the stored double is just under 2.675.

## Known limits

- Specs outside the supported grammar raise: `+`/space sign, `0` padding, `#`, `_`, upper-case types, `,` on a float.
- Peak memory is the Mojo runtime's floor, about 2 MB above Python.

## Upgrade / run

```
git clone https://github.com/amarbaro/mojo-pyformat && cd mojo-pyformat && uv sync
mojo run -I src examples/quickstart.mojo
```
