## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Python's `format()` for numbers in Mojo, with the same digits: `{:.Nf}`, thousands separators, `g`, `e`, and `%`, rounded on the double's exact binary value as CPython does.

## Highlights

- `py_sum` keeps infinities like CPython; a width or precision that overflows raises instead of misformatting.
- README has one install block and one example; a conda recipe ships the package.
